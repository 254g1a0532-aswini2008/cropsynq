# 🌱 CropSynq — Smart Food Packaging Recommendation System

**SIH Problem Statement ID: 26236**

CropSynq is an **AI-Based Intelligent Food Packaging Material Recommendation System for Food Commodities**.

It is designed to help **farmers, sellers, and food businesses** choose suitable packaging for fruits and vegetables based on storage conditions and expected storage duration.

## 🎯 Problem

Choosing the right packaging for food commodities is often difficult because it requires knowledge about:

* Moisture control
* Oxygen and CO₂ exchange
* Storage conditions
* Food–packaging compatibility
* Expected shelf life

Incorrect packaging can contribute to moisture accumulation, spoilage, quality loss, and food waste.

## 💡 Our Solution

CropSynq provides a simple digital recommendation system.

The user enters:

1. 🍅 Food commodity
2. 🌡️ Storage condition
3. 📅 Expected storage duration

The system then provides a suitable packaging recommendation.

## 🔄 How It Works

**Commodity → Storage Conditions → Recommendation**

The prototype uses rule-based logic to demonstrate how a future AI/ML system can make packaging recommendations.

## ▶️ Run the Website

### Method 1 — Directly

1. Download the project.
2. Keep all four files in the same folder.
3. Double-click `index.html`.
4. The website will open in your browser.

### Method 2 — GitHub Pages

1. Create a **Public** repository named `CropSynq`.
2. Upload the four project files.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select:

   * Branch: `main`
   * Folder: `/ (root)`
6. Click **Save**.
7. GitHub will generate your website link.
